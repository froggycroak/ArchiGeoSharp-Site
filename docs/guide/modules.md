# 模块概览

## NuGet 模块

| 模块 | 说明 | 发布 |
|------|------|------|
| **Basic** | 几何内核 | 已发布 |
| **Depute** | OSM / 高德 / NTS / CGAL | 未发布 |
| **OpenNurbs** | Rhino 互操作 | 未发布 |
| **Raylex** | Raylib 可视化 | 未发布 |
| **Solver** | Gurobi 角度场 | 未发布 |

## API 侧栏八个分区（同级分组）

下列八项在 **API** 左侧为**同一层级**的可折叠分组；Basic 侧命名为 `Basic.XXX`：

| 侧栏分组 | 说明 | 入口 |
|----------|------|------|
| **Basic.Geometry** | Basic 几何命名空间 | [All types](/api/basic-geometry) |
| **Basic.Transform** | 变换 / 求交 / Relation | [All types](/api/basic-transform) |
| **Basic.Numeric** | 数值工具 | [All types](/api/basic-numeric) |
| **Basic.Topology** | 半边网格 / 图 | [All types](/api/basic-topology) |
| **Depute** | 扩展模块 | [All types](/api/depute) |
| **OpenNurbs** | 扩展模块 | [All types](/api/opennurbs) |
| **Raylex** | 扩展模块 | [All types](/api/raylex) |
| **Solver** | 扩展模块 | [All types](/api/grbsolver) |

前四项由 XML 生成并含类型子目录；后四项暂仅 **All types** 占位，说明见 **Guide → 扩展模块**。
