# 模块概览

| 模块 | 说明 | 公开发包 |
|------|------|----------|
| **Basic** | 几何内核（点/向量/曲线/变换/网格/体） | 已发布 `ArchiGeoSharp.Basic` |
| **OpenNurbs** | Rhino / OpenNurbs 互操作 | 未公开发包（需 Rhino） |
| **Depute** | OSM、高德、NTS、CGAL 等托管扩展 | 未公开发包 |
| **Raylex** | Raylib 可视化 | 未公开发包 |
| **GRBSolver** | Gurobi 数学规划 | 未公开发包 |
| **Rhinex** | Rhino 文档绑定 | 开发中 |

本站 API 区对未发包模块提供能力介绍，便于了解生态；运行依赖与许可请以各模块说明为准。
